# Тортики та Тістечка - Галерея рецептів

Інтерактивна адаптивна вебсторінка галереї кондитерських виробів. Роботу виконано в межах Лабораторної роботи №11 з навчальної дисципліни "Програмування: Веб-програмування".

## Сторінка на GitHub Pages
[Переглянути сайт онлайн](https://curlylikee.github.io/cakes-and-pastries/)

## Адаптивні макети

Сторінка підтримує три типи компонування для різних екранів:

1. **Мобільні пристрої, Макет 1**:
   - Одноколонкова вертикальна галерея смаколиків.
   - Компактна сітка кнопок фільтрації з двох колонок та трьох рядків.
   - Лаконічний футер з контактними даними.

2. **Планшети, Макет 2**:
   - Сітка галереї на три колонки з підписами назв під зображеннями.
   - Кнопки вибору категорій розміщено у три колонки та два рядки.
   - Горизонтальний футер сторінки.

3. **Десктоп, Макет 3**:
   - Двоколонкова структура з розташуванням галереї ліворуч та панелі фільтрів праворуч.
   - Картки десертів з відступами, однаковою фіксованою висотою, рамкою для фотографій та темним текстом на сірому фоні.
   - Виразна тінь при наведенні курсора на картку.
   - Бічна панель з подвійним повзунком калорій та вертикальним списком кнопок.

## Технології
- HTML5 семантична розмітка сторінки.
- CSS3 стилі, Flexbox, Grid, медіа-запити та сучасний селектор has.
- Чистий код без сторонніх фреймворків та без використання JavaScript.
